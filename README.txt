KP ENTERPRISES - ATS CENTRE WEBSITE

For the exact reference look:
1. Keep index.html, style.css and script.js together.
2. Put your existing KP Enterprises logo file in this folder and name it: logo.png
3. Put the second reference ATS Centre / vehicle-testing image in this folder and name it: hero-car.jpg
4. Upload all files to your GitHub repository and enable GitHub Pages.

The right side of the hero is intentionally coded as an image area, matching the second reference layout. The supplied hero-car.jpg should be the image you want displayed there.
